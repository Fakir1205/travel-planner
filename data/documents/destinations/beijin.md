# 北京旅游攻略

## 城市概况

北京，古称燕京、北平，是中国四大古都之一，拥有 3000 多年的建城史和 800 多年的建都史。作为元、明、清三代的帝都，这里汇聚了皇家气象与市井烟火。

**最佳旅游季节**：4-5月（春季）和 9-10月（秋季），气候宜人，秋色尤佳。

**推荐游玩天数**：5-6 天

## 必游景点

### 故宫博物院（5A级景区）

**简介**：世界现存规模最大、保存最完整的木质结构古建筑群，明清两代的皇家宫殿，又称紫禁城。

**门票**：60元（旺季） / 40元（淡季）
*注意：必须提前 7 天在官网或小程序预约，现场不售票。*

**开放时间**：8:30-17:00（周一闭馆）

**游览建议**：
- 建议游览时间：3-4 小时
- 推荐路线：午门进 -> 太和殿 -> 乾清宫 -> 御花园 -> 神武门出
- 珍宝馆和钟表馆值得单独购票参观
- 建议租用自动讲解器（约 20 元）或请讲解员

**交通**：
- 地铁 1 号线天安门东站下车，步行约 900 米
- 建议从午门（南门）进入，神武门（北门）只出不进

### 八达岭长城（5A级景区）

**简介**：万里长城的重要组成部分，号称“天下九塞之一”，是明长城中保存最好、最具代表性的一段。

**门票**：40元（旺季） / 35元（淡季）

**开放时间**：6:30-16:30

**游览建议**：
- 建议游览时间：3-4 小时
- 体力一般者建议乘坐缆车或滑车上山
- 北八楼是好汉坡的终点，视野最开阔
- 避开周末和节假日，建议早上 7 点前出发

**交通**：
- 市郊铁路 S2 线（黄土店站）直达
- 或在德胜门乘坐 877 路公交车直达
- 打车约 200-300 元（视堵车情况）

### 颐和园（5A级景区）

**简介**：中国现存规模最大、保存最完整的皇家园林，以昆明湖、万寿山为基址，被誉为“皇家园林博物馆”。

**门票**：30元（旺季大门票） / 20元（淡季大门票）
*联票（含园中园）：60元（旺季）*

**游览建议**：
- 建议游览时间：3-4 小时
- 推荐路线：东宫门进 -> 仁寿殿 -> 长廊 -> 佛香阁 -> 坐船游昆明湖
- 苏州街和十七孔桥是必打卡点
- 园区很大，建议穿舒适的鞋子

**交通**：
- 地铁 4 号线北宫门站下车
- 或乘坐 331 路、332 路公交车
